🔌 API Key Status
💡 Agar Groq ya Gemini ne company ki key band kar di ho: Netlify dashboard → Site settings → Environment variables → GROQ_API_KEY ya GEMINI_API_KEY edit karo → Deploys tab → "Trigger deploy" → "Clear cache and deploy". 20-30 second mein naya key live ho jaata hai.

🔄 Agar scan fail ho "model not found/decommissioned" error ke saath (AI companies models retire karte rehte hain): Netlify env vars mein GROQ_MODELS ya GEMINI_MODELS naam se naya variable add karo, comma-separated model names (naya model provider ki website se copy karo). Redeploy karo. Koi code change nahi chahiye.

📖 Quick Guide
New Customer Subscribe Kare:
1. Hotel naam daalo → Plan select karo → "Generate Key" click karo
2. Payment QR + WhatsApp button se seedha customer ko bhejo
3. VALID_LICENSES string copy karo → Netlify update karo → Deploy

Payment Confirm Hone Ke Baad:
1. Apna UPI/bank app check karke payment confirm karo
2. License card mein "🧾 Invoice" button dabao — Billing tab khulega, client already selected hoga
3. Item/amount check karke "Issue Invoice" dabao, phir 💬 WhatsApp ya ✉️ Email se seedha PDF bhej do

Customer Ka License Expire Karna:
1. Key ke saamne "Revoke" button dabao
2. VALID_LICENSES copy karo → Netlify → Update → Deploy
3. Customer ka app automatically block ho jayega
